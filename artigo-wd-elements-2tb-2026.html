WD Elements 2TB: HD externo simples para backup e mais espaço

HD portátil de 2TB com USB 3.2 Gen 1, conexão Micro-B e funcionamento plug-and-play em Windows compatível.

RESUMO DO PRODUTO

WD Elements 2TB

O WD Elements Portable de 2TB é uma solução simples para guardar documentos, fotos, vídeos e backups sem precisar abrir o computador para instalar uma unidade interna.

Capacidade2TB
InterfaceUSB 3.2 Gen 1
ConectorMicro-B
CaboUSB-A
Usoportátil
Garantia2 anos limitada

Para quem faz sentido?

É indicado para quem precisa de bastante espaço para cópias de segurança e arquivos, priorizando capacidade e praticidade em vez da velocidade de um SSD externo.

O que conferir antes de comprar

O modelo vem preparado para Windows compatível. Outros sistemas podem exigir reformatação. Como é um HD mecânico, evite impactos enquanto a unidade estiver em uso.
